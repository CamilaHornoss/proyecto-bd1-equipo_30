# Evidencias — Procedimientos y funciones

## Resultados obtenidos

Los procedimientos y funciones fueron creados correctamente en la base de datos `ProyectoTiendaOGA`.

La función `fn_CalcularImporteVenta` permitió obtener el importe de cada venta utilizando los valores históricos almacenados en `Detalle_venta`.

La función `fn_CalcularTotalComprasCliente` calculó el total acumulado por cliente y `fn_CalcularDescuento` devolvió el porcentaje correspondiente según el importe acumulado.

Los procedimientos de inserción, modificación y eliminación de productos ejecutaron correctamente las validaciones definidas.
